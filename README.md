# Визуализация графа и алгоритм Дейкстры

Небольшое учебное приложение на TypeScript и D3.js. Оно отображает взвешенный ориентированный граф и позволяет выбрать начальную и конечную вершины, чтобы найти кратчайший путь алгоритмом Дейкстры.

## Требования

- Node.js и npm

## Запуск

Установите зависимости и запустите сервер разработки:

```bash
npm install
npm run dev
```

Откройте адрес, указанный Vite в терминале.

Для production-сборки выполните:

```bash
npm run build
```

## Использование

1. Нажмите на вершину, чтобы выбрать начало пути. Она подсветится зелёным.
2. Нажмите на другую вершину, чтобы выбрать конец пути. Она подсветится красным.
3. Рёбра кратчайшего найденного пути подсветятся оранжевым.
4. Чтобы начать новый поиск, выберите вершину для нового начала. Подсветка рёбер сбросится.

Результат работы алгоритма также выводится в консоль браузера.

## Формат графа

Граф задан в `src/main.ts` как список смежности. Для каждой вершины перечислены соседние вершины и веса переходов:

```ts
type DirectedGraph = Record<string, Record<string, number>>;

const graph: DirectedGraph = {
  start: { A: 5, B: 2 },
  A: { C: 4, D: 2 },
  B: { A: 8, D: 7 },
  C: { D: 6, end: 3 },
  D: { end: 1 },
  end: {},
};
```

Например, `start: { A: 5 }` задаёт направленное ребро из `start` в `A` с весом 5. Чтобы добавить обратное направление, укажите его отдельно в списке смежности вершины `A`.

## Устройство проекта

- `src/main.ts` — пример графа, реализация алгоритма Дейкстры и визуализация.
- `index.html` — HTML-страница приложения.
- D3-модули `d3-force` и `d3-selection` используются для размещения вершин и создания SVG-элементов.

Алгоритм Дейкстры подходит для графов с неотрицательными весами рёбер.
